# Instagram-Login-Form-interface
Author: Aqsa Tariq

<br>

I've created a simple yet elegant interface of the Instagram login page using HTML and external CSS. <br> 
This project is perfect for beginners in front-end development as it focuses on structuring a clean layout without using any JavaScript.

<br>

🎨 Features
Replica of the Instagram login interface.
Includes links to sign up and log in with Facebook (not functional).
Footer links similar to the original Instagram website.

<br>

🔧 Technologies Used
HTML - For the structure of the page.
CSS - For styling the layout to closely match Instagram's login page.
